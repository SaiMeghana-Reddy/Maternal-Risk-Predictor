# High-Risk Pregnancy Prediction Model

Early detection can save lives.

This project focuses on identifying **high-risk pregnancies** using machine learning, enabling timely intervention in resource-constrained settings like rural PHCs.

---

## Problem

In many parts of India, maternal complications are detected too late.  
Frontline healthcare workers often lack tools to **identify high-risk cases early**, leading to preventable deaths.

---

## Solution

This project builds a **machine learning model** that predicts whether a pregnancy is high-risk based on key health indicators.

The goal is simple:
> Flag risk early → Enable intervention → Prevent complications

---

## Tech Stack

- Model Building: RAPID Miner (Altair AI Studio)

---

## Key Focus

In healthcare, **false negatives are dangerous**.

This model prioritizes:
- 87% High recall (catching as many high-risk cases as possible)
- Practical usability over just accuracy

---

## Real-World Use Case

- Primary Health Centers (PHCs)  
- ASHA / ANM workers  
- Rural healthcare systems  

Potential workflow:
1. Input patient data  
2. Model predicts risk level  
3. High-risk cases flagged for immediate attention
